# Edugallery - Student E-Commerce Platform

Edugallery is a Django-based e-commerce platform designed to empower college students by providing a marketplace to buy and sell products within their campus. This project was developed as part of a Bachelor of Computer Application degree.

## 📌 Features

### Core Modules:
- **Admin Panel**: Manage users, products, categories, and transactions.
- **Seller Dashboard**: List products, upload multiple images, and track orders.
- **Buyer Dashboard**: Browse products, view seller details, and make purchases.
- **User Profiles**: Personalized profiles with address management.

### Key Features:
- **Multi-image Product Uploads**: Sellers can add multiple images per product.
- **AJAX Search**: Real-time product search functionality.
- **User Authentication**: Secure login, registration, and password management.
- **Responsive UI**: Works on desktop and mobile devices.

## 🛠 Technologies Used

- **Backend**: Django 4.1, Python 3.x
- **Database**: MySQL
- **Frontend**: HTML, CSS, JavaScript, Bootstrap
- **Tools**: Visual Studio Code, Git

## 📦 Installation

### Prerequisites:
- Python 3.8+
- MySQL Server
- pip
